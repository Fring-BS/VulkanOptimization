# ⚡ Vulkan Optimization (Official Repository)

Welcome to the official repository for **Vulkan Optimization**, the ultimate Minecraft performance enhancement pack designed to unlock insane FPS and eliminate lag using Vulkan rendering technology!

---

## 📢 Important Note Regarding Source Code & File Sizes

> ⚠️ **Why are there only `.mrpack` files and no extracted source folders or CurseForge `.zip` files here?**
>
> 1. **GitHub Upload Limit:** I wasn't able to upload the raw source code folders or the CurseForge `.zip` packages directly here because their file sizes exceed the maximum upload limit that GitHub's web interface can handle.
> 2. **Why not CurseForge mirrors?** If you are wondering why I didn't just upload the CurseForge version instead—it faces the exact same issue; its size exceeds the limits too!
>
> **The Solution:** To keep this repository organized and fully working, I have provided the `.mrpack` files inside the version folders. Inside each folder, I've added a quick guide on how you can easily convert the `.mrpack` into a `.zip` using an online tool to get 100% of the configs and source code instantly!
